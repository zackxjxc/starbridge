# 客户端 UI 与交互定稿

确认日期：2026-10-26。用户确认采用第四版「石墨灰」。本文是客户端实施的最终产品规格；旧文档中三栏、多选框、筛选器和「停止排队」的设计均由本文替代。会话占用的技术约束沿用 [客户端交互与会话占用规则](client-experience-and-session-rules.md)，连接测试的技术流程沿用 [本机连接测试方案](connection-self-test-plan.md)。规格确认不等于真实网络环境验收完成，实施与验证结果另行记录。

## 视觉与窗口

- 使用 Tauri 客户端，主窗口固定 900×600 逻辑像素，禁止用户缩放和最大化。登录、注册、主界面共用同一窗口。设备列表和右侧详情各自在栏内滚动；默认本机首页在该尺寸下完整显示，不需要滚动。
- Windows 使用无系统标题栏窗口，保留原生系统阴影、圆角和细描边；不得用 CSS 阴影模拟窗口阴影。macOS 与 Linux 保留现有系统装饰。
- Windows 窗口内仅有一条 36 像素品牌／账号顶栏，保留退出登录，并提供最小化与关闭按钮；空白区域可拖动窗口，交互控件不触发拖动。浏览器预览不显示模拟窗控，其他平台不额外叠加 Windows 窗控。
- 两栏布局：左栏约 350 像素，为设备列表；右栏为本机、设备详情或所进入的功能页。没有第三个导航栏。
- 采用石墨灰配色，浅色面板为主，主要操作色 `#4e5a6a`、选中背景 `#edf0f4`、主文字 `#2b3441`、次要文字 `#667181`、分隔线 `#e1e5eb`。暗色适配保持相同层级。成功与失败分别使用固定的绿、红及明确文字，不随主题重新解释状态。
- 普通信息约 12–13 像素、次要信息 11 像素，标题约 17–18 像素。主要按钮、选中态、悬停、键盘焦点和禁用状态统一；不以大面积填色装饰普通信息。
- 「连接所有设备」采用用户确认的浅底卡片入口：四周留白、完整边框、图标底块与右箭头，保留配置说明；点击只进入右侧配置页。浅色主题普通／悬浮／按下背景为 `#f5f7f9`／`#e9edf2`／`#dce3eb`。
- 深色主按钮保持白字，普通／悬浮／按下背景为 `#4e5a6a`／`#414d5d`／`#354151`，不得被通用按钮的浅色悬浮背景覆盖；暗色主题使用对应的高对比色。
- 原型中的系统切换、测试结果演示、恢复演示、配色切换均不进入正式客户端。正式界面不得使用模拟节点、假进度或假成功结果。

## 登录、注册与恢复

- 服务地址内置为 `https://starbridge.zackxjxc.de5.net`，普通界面不显示服务器 URL、FRP 地址或端口。开发参数可以保留，不能作为用户首次使用的必填步骤。
- 登录仅包含用户名、密码；注册包含用户名、密码、确认密码。两者可互相切换。
- 「记住登录状态」默认勾选。持久化账号名、设备身份、本机名称、用途、偏好及可恢复的登录凭据，不保存明文密码。取消勾选后不得在再次启动时自动恢复登录。
- 有效登录恢复或手动登录成功后，默认进入本机页。登录失效显示同尺寸登录页，保留账号与设备信息。登出结束本机连接并撤销当前登录凭据。
- 连接组件按需启动；启动客户端、恢复登录不自动执行完整连接测试。

## 设备列表与本机页

- 默认显示当前账号的全部设备，不设复选框，不设「全部／可连接／已连接」筛选器。保留名称或用途搜索，以及在线、离线统计。
- 顺序为：本机置顶；本机已连接或正在连接的设备；可连接的在线设备；被其他连接占用的在线设备；离线设备。搜索不改变「连接所有设备」的账号范围。
- 本机名称和用途可修改，用途后带「（本机）」标识。本机连接多台时显示「已控制2台设备」等数量；本机收到连接时显示来源。其他设备被连接占用时显示「已被其他设备连接」。
- 本机页包含名称、用途、系统和必要身份信息，以及显著的「连接测试」入口。左栏本机区域也有该入口。
- 本机首页采用紧凑布局，完整保留名称、用途／备注、保存按钮、系统、设备 ID 和登录用户。备注文本框高 56 像素，长文本在框内滚动且不可拖动调整大小；不得靠隐藏溢出裁掉信息。内容超出时右侧仍可滚动，后续设备详情与设备列表保留各自滚动。
- 连接测试入口后显示「未进行连接测试」「连接测试成功」或「连接测试失败」。进行中及清理中显示实时状态，取消显示「未完成连接测试」，不能将未执行或取消计为通过。完成状态在本机重开后可恢复，并明确代表最近一次测试结果。
- 左栏底部仅保留「连接所有设备」功能导航行：图标、说明、向右箭头和当前页选中态。说明为「配置连接方式，查看进度与结果」。它只打开右侧功能页，不能直接发起连接。
- 左栏不放「终止连接」和「复制给 AI」按钮；这些操作放在右侧对应功能页。

## 单台设备操作

- 点击列表行只切换详情，不发起连接。详情展示名称、用途、系统、当前连接状态，以及能解释失败或不可连接的原因。
- 右击设备，或点击详情中的更多菜单，提供「连接设备／终止连接」「重命名设备」与「删除设备」。详情页在保存修改同一行提供独立的「删除设备」按钮，不额外增加本机首页高度。本机不提供对本机的普通连接。离线或被占用设备可以查看、重命名，不能绕过服务端准入。
- 删除需要明确确认，只移除账号的设备登记，不删除电脑文件。有关联活动连接、等待任务或连接测试时先终止，再删除。可删除本机，删除后退出登录。已删除设备的旧凭据不能通过后台刷新重新登记；用户在该设备手动重新登录后，可以再次添加。删除和凭据撤销持久化，且只能操作同账户设备。
- 名称与用途是账号下的持久设备元数据。重命名不能重建会话、改变设备 ID 或丢失连接状态。
- 点击连接先进入右侧连接配置，再由「开始连接」发起。已有同向会话直接复用，不为查看、复制或重复请求打断原连接。
- 已就绪或连接中的详情均提供醒目的「终止连接」。单台终止只处理该设备，其他连接继续保留；本次批量任务的晚回调不得将它重新接入。
- 只有真实 SSH 验证通过且会话仍活动时提供「复制 SSH」和「复制给 AI」。终止、失败或失效后立即撤下可用命令。

## 全部连接配置与结果

点击「连接所有设备」后，在右侧展示配置。连接范围是账号下除本机外的全部设备，在线、离线和占用设备均进入范围统计；离线及占用项说明跳过原因。

| 模式 | 用户文案及行为 |
| --- | --- |
| 自动连接 · 兼容性优先 | 优先尝试设备直连；无法直连时，连接数据通过中转服务传输。信息敏感环境，请选择「仅限直连」。 |
| 仅限直连 · 点对点传输 | 连接数据在设备间直接传输，不经中转服务。部分网络环境可能无法连接。无法直连时结束连接，不切换中转。 |

两种模式都需要登录和连接协商；「仅限直连」限制的是连接数据路径，不承诺零风险。普通界面使用「直连未成功」等表述，不要求用户理解「打洞」。

- 开始前列出新建、复用、跳过数量。在仅限直连模式中，已有中转默认保留，并单独统计，不计本次直连成功；用户也可明确选择断开已有中转并重建直连。
- 重建前在开始按钮附近明确说明已有 SSH 将中断，直连失败不回退。点击开始才执行。
- 运行后右侧只展示整体进度、直连就绪数、中转就绪数、失败数及分类原因，不再重复设备列表。逐台状态更新在左栏。
- 失败至少区分：设备联系失败、直连未成功、中转连接失败、SSH 验证失败。网络通道建立不等于 SSH 已可用；应展示具体阶段和原因。点击失败类别可以定位相应设备详情。
- 部分失败不回滚已成功连接。批量任务使用受限并发，重复点击不创建重复任务。
- 统一使用「终止连接」。在单台详情和右键菜单只处理一台；在全连接功能页处理本机发起的全部连接，包括已有连接、进行中请求和等待任务。全量操作先说明范围并确认，终止后不得自动恢复。
- 删除旧的「停止排队」语义。全部终止同时取消未完成工作、释放占用并使晚回调失效。正在建立与已经成功的连接都必须可以终止。
- 右侧全连接配置页在已有活动连接时也提供终止全部和复制全部，不依赖本次是否存在批量任务记录。

## 会话规则与导出

- 空闲设备没有永久控制端或执行端身份。A→B 后，A 可以继续连接空闲的 C/D；B 不能反向或向其他设备发起连接；C/D 不能连接已参与会话的 A/B。
- 服务端在同一原子操作内清理过期记录、查找同向复用、校验双方占用并预占协商会话。协商中也算占用。A→B 与 C→B 并发只能一个成功。
- 同方向重复请求复用已有会话；更换路径策略必须明确终止后重建。终止最后一条相关会话、连接失败、协商超时或设备确认离线后释放相应占用。关闭后的迟到更新不能复活旧会话。
- 导出只包含当前 SSH 已验证并仍活动的会话，包含设备 ID、名称、用途、系统、实际登录用户、已知权限、直连或中转、命令、来源电脑、Shell 和有效期说明；失败和跳过项只附原因，不伪造命令。
- 命令只适用于发起连接的本机及当前会话。断开、退出、服务重启后需要重新获取。导出不得包含密码、账号令牌、FRP 密钥或私钥。

## 连接测试

入口先显示下列精简说明，不在说明页解释测试内部拓扑或协议细节：

> 检查这台电脑是否可以正常发起和接收连接。
>
> **连接组件与安全软件提示**
>
> 我们使用 FRP 官方发布的连接组件，打包时不修改程序本体。部分安全软件可能将其误报或隔离，导致连接失败。
>
> 测试过程中可能出现防火墙提示。请核对程序名称和路径，并在防火墙中允许 StarBridge 及其连接组件进行网络通信。
>
> 如果提示风险，请先核对程序来源及官方文件校验结果。确认属于误报后，再按安全软件提示放行相关文件。

- 提供「组件来源与校验」；仅在本机为 Windows 时显示「Windows 处理方法」，Mac 不显示此项。不能根据当前选中的远端系统判断本机提示。
- 不把下载地址当作运行时文件校验通过，不宣称任意告警都是误报；不自动加白名单、关闭防护或修改防火墙。
- 只有本机空闲且策略允许中转时可以开始。已有连接或批量任务时提示先终止，不自动断开。测试期间拒绝普通建联，结束后释放占用。
- 使用正式运行组件、隔离的临时 SSH 配置，经远程中转真实连接回本机并验证登录和固定数据回传。不能用延迟动画、端口连通或 FRP 启动成功冒充整体通过。
- 运行中可取消、查看详情；结束后可重试、查看分项结果。成功、失败、取消和超时都先完成清理，再显示终态。清理失败不能显示成功。
- 测试范围与技术细节可在结果和详情中呈现：默认不验证跨设备直连，文件传输未测试则明确标注。网络超时没有拦截证据时不归因为杀毒软件。
- 服务端不支持诊断能力、策略禁止中转或使用外部 SSH 无受限测试授权时明确显示尚未验证，不回退成假成功或自动改变策略。

7. 连接测试执行真实路径，空闲门槛、取消、清理、状态记忆和系统专属说明正确；不能以原型状态代替真实测试结果。

9. 在 Windows 原生窗口验证 900×600 客户区、系统阴影、唯一顶栏、拖动、最小化和关闭；默认本机首页完整显示且无需滚动，长备注在文本框内滚动，其他详情及设备列表仍可滚动。原生实测与最终打包结果另行记录，浏览器检查不能替代此项。
