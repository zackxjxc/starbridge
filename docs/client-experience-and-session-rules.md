# 客户端交互与会话占用规则

确认日期：2026-10-26。本文记录已确认的产品设计，作为后续三栏原型、客户端和服务端实现的依据；本文提交不代表这些功能已经实现。与旧文档中的窗口布局、登录入口、自由双向并发或复制行为有冲突时，以本文为准。

## 目标与当前状态

UI 以用户容易理解和操作为首要目标，功能逻辑可以据此调整。设备没有永久的“控制端”和“执行端”身份；任何空闲设备都可以发起连接或接受连接，连接期间按下述占用规则限制操作。

当前客户端已经使用 Tauri，同一设备同时准备 SSH 登录密钥和接收连接的服务，并支持多会话。现窗口初始为 1200×820、最小 780×600，仍可调整尺寸；界面仍是双栏卡片布局。现服务端允许 A→B 与 B→A，以及其他设备指向 A/B 的连接同时存在，并在重复 A→B 时替换旧会话。这是当前已实现的自由混合会话设计，尚未实施本文规定的固定窗口、占用准入和同向复用规则。

## 窗口、登录与记忆

- Tauri 主窗口固定为 900×600 逻辑像素，登录页和登录后的三栏主界面使用相同尺寸，切换时不改变窗口大小；不提供拖拽缩放和最大化。系统显示缩放仍由操作系统处理。
- 客户端内置固定服务地址 `https://starbridge.zackxjxc.de5.net`。用户界面不显示或要求填写服务器 URL、FRP 地址及端口；开发和部署配置不进入普通用户操作流程。
- 首次进入显示简洁的用户名、密码和登录按钮。登录成功后进入三栏主界面，并持久化登录状态、设备身份、账号名、本机信息、用途备注和使用偏好。
- 再次启动自动读取这些信息并尝试恢复登录；有效登录可直接进入主界面。登录失效时回到同尺寸登录页，保留账号名和设备信息，不要求重新配置服务器。
- 记住账号、设备与偏好不等于明文保存密码。持续免登需要独立实现可撤销的登录凭据恢复机制。当前代码仅恢复未过期的 24 小时访问令牌，账号名尚未独立于该令牌保存；不能将现状描述为已完成长期免登。

## 三栏主界面

窗口外框和三栏位置保持稳定；长设备列表与详情各自在栏内滚动，不把整个窗口变成长网页。

| 区域 | 核心内容与操作 |
| --- | --- |
| 左栏 | 账号、本机名称、本机连接状态及必要的导航与设置入口。服务器和底层组件配置不占据主界面。 |
| 中栏 | 可搜索、可多选的设备列表；每行以设备名称、用途备注和清晰状态为主。用途备注帮助用户识别“开发机”“构建机”等用途，并进入导出信息。 |
| 右栏：单选 | 所选设备的名称、用途、系统、状态及连接操作；SSH 真正就绪后提供命令和复制入口。已建立的同向连接直接复用。 |
| 右栏：多选 | 显示选择数量、批量连接入口、逐设备进度与结果；可复制或导出已成功且 SSH 就绪的所选设备信息。 |

选中和连接是独立动作：选中设备只切换详情，多选不会自动发起连接。离线或被占用的设备仍可查看，但连接入口应说明不可连接的原因；不能只用颜色表达状态。

A→B 时，A 显示“已连接 B”，B 显示“已被 A 连接”。协商期间使用“正在连接 B”或“A 正在连接本机”，不提前声称已经可用。A 同时连接多台时显示数量及目标名称列表；连接方向是当前状态，不把用户标记成永久角色。

## 会话占用与准入

活动会话包括 `Negotiating` 和 `Connected`；`Closed`、`Failed` 及已清理的过期会话不占用设备。占用从服务端接受请求并创建 `Negotiating` 会话时开始，不等 SSH 命令出现后才开始。

限制对象是 StarBridge 设备会话及其方向占用，不是 SSH shell 数量。同一已建立通道内打开多个 SSH shell，不视为另一台电脑重新接入。规则保留 A 对多个空闲目标的一对多和批量能力，不是全局一对一限制。

| 设备状态 | 可以发起新连接 | 可以接受新连接 |
| --- | --- | --- |
| 空闲且服务就绪 | 可以连接空闲设备 | 可以接受符合条件的请求 |
| 正在连接或已连接其他设备，且没有入站会话 | 可以继续连接其他空闲设备，用于一对多和批量操作 | 不可以 |
| 正在被连接或已被连接 | 不可以 | 不可以接受其他设备的新请求 |

因此，A→B 建立或协商后：

- A 可以继续连接空闲的 C、D，形成 A→B/C/D。
- B 不可以反向连接 A，也不可以在被连接期间向 C/D 发起新连接。
- 尚未加入连接的 C、D 不可以连接 A 或 B；A 和 B 均已参与活动会话。
- 结束 A→B 只释放这条会话。若 A→C 仍活动，B 恢复空闲而 A 仍不能接受其他设备的连接；A 的最后一条出站会话结束后才恢复空闲。

同一发起设备重复请求同一目标时，返回已有活动会话，保留其会话 ID、路径策略、本地端口和 SSH 配置，不断开或重新创建。已有会话仍在协商时也复用并显示其进度。重复请求不是修改路径策略的入口；更换现有会话的策略需要明确结束后重新连接。

服务端是准入规则的最终裁决者。创建流程必须在同一原子操作内完成：清理过期会话、验证设备身份和能力、查找同向可复用会话、检查双方占用、预占并创建新会话。并发的 A→B 与 C→B 只能有一个成功，另一方得到明确的占用结果。客户端按钮状态仅用于提示，不能代替服务端检查。

占用由活动会话推导，或与会话状态保持原子一致；不能因为残留历史记录而持续占用。主动断开、连接失败和协商超时应结束会话并释放对应占用；设备退出或掉线确认后结束相关会话。现有心跳离线阈值为 30 秒、协商期限为 600 秒，可沿用为初始实现参数；正常在线的已连接会话不按创建后十分钟强制结束。

服务器重启后原活动会话结束、占用释放；客户端不能继续导出旧会话的命令。对已结束会话的迟到状态更新不能将其复活；占用校验和状态更新都必须先处理过期状态。若设备仍有其他活动会话，仅释放结束的会话，不提前将整台设备标成空闲。

## 批量连接与取消

批量连接按所选目标逐项执行，服务端对每一项执行相同的原子准入规则；整批不是一个必须全成或全败的事务。已成功的项目不因其他项目失败而回滚，同向已有会话直接复用。

每一行分别显示排队中、连接中、SSH 就绪、已复用、失败、被占用、离线或已取消，并提供具体原因。汇总区显示完成数量和各类结果；“已复用”仅在原会话的 SSH 仍就绪时计入可复制成功项，不能将“已发送连接请求”计作成功。

取消批量任务停止尚未执行的项目；已经发出的请求继续跟踪结果，已经建立或复用的连接保持不变。取消不是“断开全部”，尤其不能误断任务开始前已经存在的连接。若用户需要断开，应通过明确的单项或所选连接断开操作执行。

离线、占用和失败项可以保留选择供查看或重试，但不能混入可执行 SSH 信息。批量结果允许部分成功，复制和导出只包括用户当前所选且 SSH 已就绪的成功项，并明确列出未包含的设备及原因。

## SSH 信息复制与导出

复制入口必须等待真实 SSH 就绪：路由、本地访问端口和目标 SSH 访问已经验证，可执行命令已生成；仅设备在线、FRP 进程启动或通道状态为 `Connected` 不足以宣称 SSH 已可用。断开、失败或过期后立即停止将原命令标成可用。

单选复制与多选导出使用一致的数据结构，每台设备至少包含：

| 字段 | 含义 |
| --- | --- |
| 节点 ID | 目标设备的稳定标识，用于区分同名设备 |
| 名称 | 用户可识别的设备显示名称 |
| 用途 | 设备用途备注；未设置时明确为空或未设置，不推测 |
| 系统 | 目标操作系统及必要的平台信息 |
| 登录身份与权限 | 实际 SSH 登录用户及已确认的普通用户、管理员或系统权限；未知时明确标注未知 |
| SSH 命令 | 当前会话验证后生成、可直接执行的命令，引用本次会话的端口和配置 |
| 执行来源电脑 | 命令应在哪台发起电脑执行，包含该电脑名称和节点 ID |
| Shell | 命令适用的 PowerShell、cmd 或其他 shell，并使用对应转义规则 |
| 有效范围与生命周期 | 仅在指定发起电脑和该活动会话期间有效；断开、客户端退出、服务重启或重建后需重新获取 |

命令在发起电脑执行；从 A 导出的本地端口或配置路径不能当成可在 B、C 或任意电脑执行的通用连接地址。复用已有会话时引用其现有命令，不为了复制或导出重新建联。复制到其他位置的静态文本无法自动失效，因此必须带上来源和生命周期说明。

导出不包含密码、访问令牌、刷新令牌、设备身份令牌、FRP 认证或会话密钥、私钥，以及无需用户理解的服务器或 FRP 地址。主机权限未知时不得默认描述为管理员权限。

## 实施与验收

先完成三栏交互原型评审，再调整 UI、核心 API 和服务端准入；不能只隐藏界面入口而继续允许旧规则从 API 建联。当前自由双向并发的相关测试需要在实施新规则时同步调整，保留每台空闲设备均可发起或接收连接的能力。

| 场景 | 预期结果 |
| --- | --- |
| 首次登录与再次启动 | 同一 900×600 窗口；只输入账号密码；服务地址内置；账号、设备与偏好恢复，登录失效不清空这些信息 |
| A→B 后 A→C、A→D | B/C/D 原为空闲时均允许；A 可看到三项独立结果 |
| A→B 后 B→A、B→C | 均拒绝，说明本机正在被 A 连接 |
| A→B 后空闲 C/D→A/B | 均拒绝，说明目标正在参与连接 |
| A→B 与 C→B 并发抢占 | 只能一项成功；协商中已占用，不出现双重占用 |
| 重复 A→B | 返回同一活动会话；会话 ID、端口和配置不重建，原业务不中断 |
| A→B/C 中断开 B | B 空闲；C 会话持续；A 最后一条出站结束后才空闲 |
| 失败、协商超时、掉线与重启 | 对应会话和占用释放；迟到状态不能复活旧会话；已结束命令不可继续复制为有效命令 |
| 多选成功、失败、占用、离线混合 | 分别呈现结果；保留成功连接；仅复制所选且 SSH 就绪项 |
| 批量包含已有会话后取消 | 已有会话复用且不中断；未执行项取消；已发起项继续显示结果 |
| SSH 尚未就绪或命令来自另一电脑 | 不提供误导性可执行复制；导出清楚标明来源电脑、Shell 和生命周期 |

本次仅确认并保存规格；窗口锁定、三栏 UI、账号独立记忆、用途备注、设备占用、同向复用、批量连接和完整导出仍需后续实现与验证。
